# job-search

Free job-search autopilot: a daily digest of new DevOps / SRE / Platform roles, instead of searching LinkedIn, Wellfound, Indeed and Naukri one by one.

## Idea (v1)
- Saved searches with filters: role, location, remote / on-site / hybrid, experience fit, posted within N days.
- Free-tier aggregators only (no paid job API): JSearch free tier + Adzuna free tier, cached daily refresh.
- Resume upload + local parsing, with user correction of titles, skills and years of experience.
- Dedupe + fit scoring, Top 10 new jobs only, deep-link apply on the source site.
- No auto-apply, no login bypass, no CAPTCHA bypass.
- Naukri / Wellfound: native alerts + paste-a-link import in v1 (no scraping backbone).
